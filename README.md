Student Management System

A simple and responsive web-based Student Management System developed using HTML, CSS, and JavaScript.

Features

- Add new student records
- View student records
- Edit student details
- Delete student records
- Search students
- Filter students by course
- Calculate average marks
- Display top performer
- Store data using browser Local Storage
- Responsive design for mobile and desktop

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

Student Details

The system stores:

- Roll Number
- Student Name
- Course
- Year
- Marks
- Phone Number

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Start adding student records.

Project Purpose

This project was developed as a mini project to understand web development fundamentals, CRUD operations, JavaScript, and browser Local Storage.
